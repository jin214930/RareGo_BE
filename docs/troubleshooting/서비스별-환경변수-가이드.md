# 서비스별 환경변수 가이드

## 개요

## 🔐 보안 원칙

### 1. 최소 권한 원칙
각 서비스에 **필요한 시크릿만** 주입:
- OAuth2 시크릿 → auth-service만
- 결제 API 키 → payment-service만
- AWS 키 → product-service만 (S3 사용)

### 2. @ConditionalOnProperty 활용
선택적 기능은 프로퍼티로 활성화:
```java
@Configuration
@ConditionalOnProperty(name = "rarego.s3.enabled", havingValue = "true")
public class S3Config { ... }
```

### 3. 환경변수 기본값 설정
```yaml
spring:
  data:
    redis:
      host: ${SPRING_DATA_REDIS_HOST:localhost}
```

## ⚠️ 흔한 실수

### 1. OAuth2 환경변수 복사
```yaml
# ❌ 잘못된 예: notification-service에 OAuth2 환경변수
SPRING_SECURITY_OAUTH2_CLIENT_REGISTRATION_KAKAO_CLIENT_ID: ${KAKAO_CLIENT}
```
→ Kakao provider 설정이 없어서 서비스 시작 실패

### 2. application.yml 템플릿 복사
각 서비스의 `application.yml`도 필요한 설정만 포함해야 함.

## 📁 관련 파일
- `docker-compose.yml` - 환경변수 주입
- `*-service/src/main/resources/application.yml` - 서비스별 설정
